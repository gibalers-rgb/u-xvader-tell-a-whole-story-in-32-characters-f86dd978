A program that writes one Wi-Fi network name of at most 32 characters: the funniest name that hints at a whole story. It keeps a shortlist of hand-written candidate names, scores each against the judge's own rubric (the joke lands on the first read, it implies a whole story, it is fresh, it is tight), and writes the winner to `/output/entry.txt`. The winning name:

> He Proposed, I Changed Password

(A proposal answered not with words but with a changed Wi-Fi password — two people, one question, one quiet revenge.)

## Run it

```sh
python3 main.py
```

Writes `/output/entry.txt` (31 characters, no trailing newline) and checks the winner against the gate (1–32 characters, not only white space) before exiting.
